🚀 Calcpad Suite Py — una hoja de cálculo de ingeniería que ejecuta Python real

Estoy construyendo una herramienta que une la claridad de un documento de cálculo (tipo Mathcad/Calcpad) con la potencia de Python científico.

👉 Escribes un script de Python con numpy y matplotlib, y Calcpad Suite Py lo ejecuta en el Python real del sistema y lo renderiza como un informe: fórmulas, variables y gráficas embebidas — sin exportar nada.

Lo que ya funciona:
✅ numpy + matplotlib reales (las librerías que tengas instaladas)
✅ Control total de qué se muestra: mostrar u ocultar variables, títulos y texto sin tocar el cálculo
✅ Salida línea por línea mientras Python ejecuta
✅ Gráficas INTERACTIVAS con hover dentro del propio informe (vía plotly): pasas el cursor por el mapa de color y ves el valor justo donde apunta

Lo que viene 🔜 (lo iré sumando a medida que avanzo con mis validaciones FEM):
🎯 Inspección de mallas en 3D con hover y rotación dentro del documento — como en MATLAB.

Es un proyecto en evolución y de código abierto. Cada validación que hago le suma una capacidad nueva.
